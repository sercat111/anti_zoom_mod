# Anti Zoom Mod

Fabric-мод для Minecraft `1.21.11`, который сбрасывает сторонний зум, когда игрок держит оружие.

## Что делает мод

- Отменяет уменьшение FOV, похожее на Zoomify, WI Zoom, Logical Zoom, Ok Zoomer, Just Zoom, FabriZoom, Camera Utils, OptiFine zoom и похожие моды, если в главной или второй руке находится защищённое оружие.
- Распознаёт ванильные мечи, топоры и трезубец.
- Эвристически распознаёт оружие из Vic's Point Blank / Point Blank и похожих модов по id предмета: `pointblank`, `vic`, `gun`, `rifle`, `pistol`, `deagle`, `revolver`, `sniper`, `shotgun`.
- Дополнительно считает оружием предметы с положительным `generic.attack_damage` в главной руке.
- Не блокирует ванильные луки и арбалеты, чтобы не ломать обычную ванильную механику прицеливания.

## Сервер и одиночный мир

- На сервере мод кикает игроков без установленного клиентского Anti Zoom Mod.
- На клиенте для обычных серверов защита включается только после подтверждения, что Anti Zoom Mod установлен на сервере.
- В одиночном мире защита включается настройкой `Enable in singleplayer worlds` / `Включить в одиночных мирах`.
- Если Mod Menu установлен, настройка доступна в экране конфигурации мода.
- Если Mod Menu не установлен, настройку можно поменять в `config/anti_zoom_mod.properties`.

## Сборка

```bash
gradle build
```

Если вы хотите добавить Gradle Wrapper локально, выполните `gradle wrapper --gradle-version 8.14.3`, но wrapper jar не хранится в репозитории, чтобы GitHub/интерфейс не ругался на бинарные файлы.

Готовый jar появится в `build/libs/`.

## IntelliJ IDEA

1. Откройте папку проекта как Gradle-проект.
2. Дождитесь импорта зависимостей.
3. Запустите Gradle-задачу `genSources`, если нужны исходники Minecraft в IDE.
4. Для тестового клиента используйте Gradle-задачу `runClient`.
5. Если IDEA просит wrapper, выберите локальный Gradle в настройках Gradle проекта или сгенерируйте wrapper у себя локально.

## Настройка под конкретный оружейный мод

Если у оружия из другого мода нестандартные id и атрибуты, добавьте нужные ключевые слова в метод `isPointBlankWeaponId` в `WeaponZoomBlocker`.
